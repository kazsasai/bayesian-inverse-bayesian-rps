# Reproducing the figures (Paper A)

All data figures are regenerated by self-contained Python scripts in this
directory (`figures/scripts/`). Schematic **Fig 1** is hand-drawn and has no
build script.

## 1. Requirements

```bash
pip install numpy matplotlib powerlaw
```
(Python ≥ 3.9. `powerlaw` is only needed for the power-law fits.)

## 2. Get the data

Large simulation outputs are archived on **Zenodo** (DOI: `10.5281/zenodo.20533918`).
Two ways to make the scripts find it:

```bash
# Option A — extract the archive into <repo>/data/
tar xzf paperA_data.tar.gz -C /path/to/repo/data/

# Option B — point an environment variable at the extracted data
export PAPERA_DATA=/path/to/extracted/data
```

Path resolution (`figdata.py`) searches, in order: `$PAPERA_DATA` → `<repo>/data`
→ the in-repo `simulation/` tree. So if you cloned the full repository including
`simulation/`, the scripts run with no extra download.

A few small inputs are **bundled** in `figures/scripts/data/` (BO-tournament
summary, σ-trajectories for the smoothing figure, and the internal-vs-behaviour
arrays for Fig 10); those figures build with no external data.

## 3. Build

```bash
cd figures/scripts
python build_all.py          # every figure
python build_all.py 3 6 8    # selected figures
```

The cumulative-CCDF builders (Fig 3, 4, 6) cache intermediate CCDFs under the
data tree and may take a couple of passes; `build_all.py` re-invokes them
automatically.

… at the top-left, no per-panel titles (descriptions live in the captions).

### Table

The appendix `x_min`/fit-convention sensitivity table (`tab:xmin`) is
reproduced by `recompute_tab_xmin.py` (same data path resolution via
`figdata`; reads the `reward_huge` `bib-bib` `m=50` durations and prints the
table rows plus the cross-design spread).

The heuristic on-off reduction of Appendix `app:heuristic` is reproduced by
`reduced_map_intermittency.py` (self-contained; no external data). It iterates
the two-hypothesis log-odds walk with conditional reinjection — recovering the
power-law exponent ~3/2 (Sparre–Andersen) — and the always-on contraction
variant, which collapses to exponential return times (the smoothing ablation).

## 5. Regenerating the source data (optional)

The simulation outputs themselves are produced by the engines/runners under
`simulation/` and `simulation_tie_mode_ablation/files/`; see
`zenodo_data_manifest.txt` for the directory layout and the run scripts that
generated each tree.
