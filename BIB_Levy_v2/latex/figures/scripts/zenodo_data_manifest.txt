==============================

the relative paths shown) so that extracting the archive to <repo>/data/ — or
pointing $PAPERA_DATA at the extraction dir — lets `build_all.py` run.

Relative paths are given from the data root (= the in-repo tree root that holds
simulation/ ; figdata.py searches $PAPERA_DATA, <repo>/data, then <repo>).

Notes
-----
* A *figure-only* subset (just the JSON/NPZ files the build scripts open) is far
  smaller than the 16 G full tree; if archive size matters, archive only the
  files dereferenced by build_all.py rather than the whole data/ trees.
* The huge runs use T = 2e5 steps; analysis window = last 1e5 (laminar/argmax)
  with N_h = 10, m = 50 unless a sweep varies them.
